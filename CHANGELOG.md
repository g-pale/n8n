# История изменений

## 2026-01-19 - Исправление проблем с сетью и конфигурацией

### Исправленные проблемы

1. **Проблема с Docker сетью**
   - **Симптомы**: HTTP 502, ошибка `dial tcp: lookup n8n on 127.0.0.11:53: no such host`
   - **Причина**: Контейнеры n8n и caddy были в разных сетях (`n8n_default` и `n8n_n8n_network`)
   - **Решение**: Создан скрипт `fix-config.sh` для автоматического исправления конфигурации и сети

2. **Проблема с ключом шифрования**
   - **Симптомы**: Контейнер n8n постоянно перезапускался с ошибкой `Mismatching encryption keys`
   - **Причина**: Несовпадение ключа шифрования в `.env` и в файле конфигурации volume
   - **Решение**: Создан скрипт `fix-encryption-key.sh` для удаления старого файла конфигурации

### Добавленные скрипты

- **`fix-config.sh`** - автоматическое исправление конфигурации и сети
  - Определяет режим работы (HTTP/HTTPS)
  - Создает/обновляет `.env` файл
  - Переключается на HTTPS конфигурацию если нужно
  - Создает сеть `n8n_network` и пересоздает контейнеры

- **`fix-network.sh`** - диагностика проблем с сетью
  - Показывает текущее состояние контейнеров и сетей
  - Дает рекомендации по исправлению

- **`cleanup.sh`** - очистка временных файлов и бэкапов

### Обновленные скрипты

- **`update.sh`**
  - Добавлена поддержка HTTPS режима
  - Автоматическое определение режима работы

  - Проверка подключения контейнеров к сети

- **`copy-files.sh`**
